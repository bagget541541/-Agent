## 🔧 根本原因分析

### 原因 1：源数据质量问题（占比 50%）

**问题示现**：
- 推卡菜单、网站导航混在原始数据中
- 表格被截断
- 脚注格式混乱

**来源**：
- 从 Word 或网页爬取数据时，模板/侧边栏/页脚被一起包含
- HTML to Markdown 转换不完美

**影响层级**：源头问题，后续脚本无法完全弥补

### 原因 2：脚本过滤规则不完整（占比 35%）

**缺陷**：
- 垃圾行过滤 `_is_garbage_line()` 虽已增强，但仍有遗漏（推卡菜单、地址等）
- 空字段删除逻辑未覆盖所有情况
- 内部标记字段 `_*` 未被隐藏

**影响层级**：脚本优化空间大

### 原因 3：数据提取逻辑简化（占比 15%）

**缺陷**：
- 亮点提取直接采用首段文本，未做去重/去噪
- 活动时间混淆（发布时间 vs 活动时间）
- 重复条目未能完全去重（相似度阈值需调整）

**影响层级**：需要调整提取策略和参数
