## ⚠️ 待优化项（需进一步完善）

### 1. 垃圾信息过滤不完全
**问题**：
- 导航菜单词语仍出现在文本中（如"上海市"、"中信银行银联标准IC信用卡"）
- "附件："列表中的文本未完全清除
- 网页尾部垃圾内容未彻底剔除

**根本原因**：
- Markdown 中的垃圾信息在**段落文本内部**而非作为独立行出现
- 需要在源数据转换时更早地过滤，而非后处理

**优化建议**：
```python
# 在 _clean_publish_body() 中添加更激进的过滤：
# 删除 "中信银行·情侣主题信用卡\n免费申请" 这类模式
drop_footer_patterns = [
    r"中[信农]银行[·•][^\n]*信用卡\n\s*免费申请",
    r"网上银行[\s\S]{0,100}?关于我们",
]
```

### 2. 结构化字段仍显示过多细节
**问题**：
- "详情"字段现在仍显示完整内容，导致冗长
- 活动内容应该摘要而非完整显示

**优化建议**：
- 改进 `_truncate_text()` 的截断长度（当前 120 字）
- 对"详情"字段只保留前 2-3 句话
- 对"活动内容"字段提取核心的时间、门槛、奖励三个要素

### 3. 附件/参考信息处理
**问题**：
- 仍然显示完整的"附件列表"
- "原文摘要"未完全隐藏

**建议的处理流程**：
```
原始 Markdown
   ↓
识别附件行（^附件[:：]）→ 删除该行 + 后续相关行
识别垃圾导航 → 逐行剔除
   ↓
提取有效信息（亮点/时间/人群等）
   ↓
输出清洁 HTML
```
